# Pokédex

A Pokédex app built with Expo on [PokeAPI](https://pokeapi.co): browse and
search all Pokémon, see their stats and evolution chain, keep favorites, and
compare two Pokémon.

## Run it

No API key needed.

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go.
